MEADOW PHONE WEBSITE — READY TO HOST

This is a complete static site. index.html contains the game, styles, images and JavaScript. It has no API calls, remote database, AI inference, paid services or external asset dependencies.

For a free GitHub Pages deployment:
- Use a GitHub Free account and a public repository.
- Upload index.html and .nojekyll to the repository root.
- In Settings > Pages, publish the main branch root folder.
- Use the generated HTTPS GitHub Pages link in Teams.
- No paid domain, private repository, Codespaces or paid service is required for this deployment. Do not enable unrelated paid services.
- GitHub applies its own service terms and usage limits. Hosting availability/pricing can change; this is not a promise about future provider policy.

Keep student records out of the repository. Farms, purchase reasons and reflections stay in each visitor’s browser; report downloads are created on that device. GitHub receives normal site requests, not the browser’s saved farm. See its privacy policy for visitor request logging.

Use Student_Instructions.txt for the class, adding the actual new site link after deployment. Do not distribute the old ChatGPT-hosted link after it has been removed.

For phone usability, the site includes large touch targets and a bottom bar for figures, purchases and reports. Prefer a full phone browser over an embedded Teams/ChatGPT viewer.
